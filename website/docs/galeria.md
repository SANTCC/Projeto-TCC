## Como as capturas foram feitas

```bash
npm install --prefix tools/screenshots
CHROME_PATH=/usr/bin/chromium npm run screenshots
npm run about
```

Detalhes do pipeline (PostgREST simulado, vendorização de CDNs e catálogo de telas) em
[Documentação ilustrada](/operacao/documentacao-ilustrada). A página navegável com as mesmas capturas, em
formato de apresentação, é o
[`about.html`](https://github.com/SANTCC/Projeto-TCC/blob/main/about.html).
